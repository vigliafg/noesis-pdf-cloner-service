Noesis PDF Cloner — Guide

Noesis PDF Cloner opens a PDF, translates the pages you choose and preserves the layout: text, images, tables and page numbers stay in place, only the language changes. The result is a translated PDF (or a ZIP of single pages). Use it from the browser or from the command line (CLI).

Overview

Translation is produced by the pdf2zh_next v2 engine (typesetter BabelDOC). Pages are processed in blocks of 100, so even a whole book proceeds smoothly. Jobs enter a queue and progress can be followed in real time.

🧩 Layout preserved

Layout, figures and tables stay as in the original.

👁️ Error-proof preview

Thumbnail with physical number + printed label.

⏱️ Estimate first

Time and cost computed before starting.

🌐 Three engines

Google, Bing (free) and LLM via OpenRouter.

🔑 BYOK

For LLM you use your key: it is not stored.

⚡ Cache

Already translated pages are instant.

🧵 Queue & parallel

Multiple jobs at once, with live progress.

🐳 Docker

Ready multi-platform image, nothing to install.

Getting started

  1. Start the service (see Installation).
  2. Open the browser at http://127.0.0.1:18080.
  3. Click ＋ to start a new job.
  4. Drop the PDF, choose pages, language and engine.
  5. Click Next through the last step, then start.
  6. When done, download the PDF (or the ZIP).

Job states

 queued ──▶ running ──┬──▶ done      (file ready: download)
   ▲                  ├──▶ error     (see the log in the details)
   └── promoted       └──▶ cancelled (cancelled)
        (after a restart: interrupted)

Before starting, if the service requires it, tick the "I accept the Terms of use" box (with links to Terms and Privacy).

Pages & numbering

You can use all for every page, a single page (7), a range (100-103) or a list (3,5,10-12).

Watch out for double numbering. In a PDF the physical number (position in the file) and the printed number on the page may differ. The preview shows both:

  ┌───────────────┐   physical number: 156   ← position in the file (what you type)
  │   …page…      │   printed label:   142   ← number printed on the document
  └───────────────┘

In the Engine step the estimate of time and cost for your selection is shown. For llm the cost is charged to your OpenRouter account.

OpenRouter key (BYOK)

To use the llm engine, enter your key. The key:

  • is used only to perform the requested translations;
  • is not stored on the server and not logged;
  • stays in your browser; costs go to your OpenRouter account.
  browser ──(key in the request)──▶ server ──▶ pdf2zh_next
      ▲                                          │
      └────── the key is NOT retained ───────────┘

In the Engine step, selecting llm shows the field: paste the key (hidden, 👁 to reveal) and click Validate key and model for an immediate check. Tick "Remember in this browser" to avoid re-entering it next time; Forget clears it.

If you have no key, use google or bing: they work immediately and require no sign-up.

Download

  • A single PDF: all translated pages in one file.
  • ZIP of single pages: one PDF per page.

Installation

The easiest way is Docker:

docker run -d --name noesis -p 18080:18080 -v noesis-data:/data \
  ghcr.io/vigliafg/noesis-pdf-cloner-service:latest

Or from source on Linux/macOS/WSL:

git clone https://github.com/vigliafg/noesis-pdf-cloner-service
cd noesis-pdf-cloner-service
./install.sh

Full installation guide (Windows, offline, API+worker): docs/INSTALL.md.

Configuration

The simplest way is the Settings page, opened from the computer that hosts the service:

http://127.0.0.1:18080/settings

You will find limits, performance, cleanup, engine, the OpenRouter key and the legal options. Edit and press Save, then restart: ./noesis restart (Docker: docker compose up -d).

The page is private: it only answers from the local computer (or the one hosting Docker). Alternatively, from the console: ./noesis config --show, ./noesis config --set KEY=VALUE, ./noesis config --list.

API & CLI

./run-cli.sh book.pdf -p 100-103 --src en --dst it --engine google

For the llm engine from the CLI: export OPENROUTER_API_KEY (recommended) or use --llm-api-key-file; --llm-api-key is convenient but visible in ps/history.

Details in the README.

Uninstall

./uninstall.sh            # interactive choice of what to remove
./noesis uninstall --all  # no trace left

With Docker: docker rm -f noesis (and remove the noesis-data volume if no longer needed).

FAQ

Some pages translate instantly: why?

They are already in the cache: the same document and language are not translated twice.

Can I translate a whole book?

Yes, with all. Recommended for texts you have the right to process.

Can the translation contain errors?

It is an automatic translation: always verify it. See the legal notes.

Where do my files go?

They stay on your server; documents and artifacts are removed automatically (24h/72h). See the Privacy Policy.
