Noesis PDF Cloner — Guida

Noesis PDF Cloner apre un PDF, traduce le pagine che scegli e ne preserva il layout: testo, immagini, tabelle e numeri di pagina restano al loro posto, cambia solo la lingua. Il risultato è un PDF tradotto (o uno ZIP di pagine singole). Si usa dal browser oppure da riga di comando (CLI).

Panoramica

La traduzione è prodotta dal motore pdf2zh_next v2 (typesetter BabelDOC). Le pagine vengono lavorate a blocchi da 100, quindi anche un libro intero procede senza bloccarsi. I lavori entrano in una coda ed è possibile seguirne l'avanzamento in tempo reale.

🧩 Layout preservato

Impaginazione, figure e tabelle restano come nell'originale.

👁️ Anteprima anti-errore

Miniatura con numero fisico + etichetta stampata.

⏱️ Stima prima dell'avvio

Tempo e costo calcolati prima di partire.

🌐 Tre motori

Google, Bing (gratuiti) e LLM via OpenRouter.

🔑 BYOK

Per l'LLM usi la tua chiave: non viene salvata.

⚡ Cache

Le pagine già tradotte sono istantanee.

🧵 Coda e paralleli

Più lavori insieme, con avanzamento live.

🐳 Docker

Immagine pronta multi-piattaforma, senza installare nulla.

Per iniziare

  1. Avvia il servizio (vedi Installazione).
  2. Apri il browser su http://127.0.0.1:18080.
  3. Clicca ＋ per iniziare un nuovo lavoro.
  4. Trascina il PDF, scegli le pagine, la lingua e il motore.
  5. Premi Avanti fino all'ultimo passo, poi avvia la traduzione.
  6. A fine lavoro scarica il PDF (o lo ZIP).

Stati di un lavoro

 queued ──▶ running ──┬──▶ done      (file pronto: scarica)
   ▲                  ├──▶ error     (vedi il log nel dettaglio)
   └── promosso       └──▶ cancelled (annullato)
        (dopo un riavvio: interrupted)

Prima di avviare, se il servizio lo richiede, spunta la casella «Accetto i Termini d'uso» (con i link a Termini e Privacy).

Pagine e numerazione

Puoi indicare all per tutte le pagine, una sola pagina (7), un intervallo (100-103) o un elenco (3,5,10-12).

Attenzione alla doppia numerazione. Nei PDF il numero fisico (posizione nel file) e il numero stampato sulla pagina possono non coincidere. L'anteprima mostra entrambi:

  ┌───────────────┐   numero fisico:   156   ← posizione nel file (quello che scrivi)
  │   …pagina…    │   etichetta:       142   ← numero stampato sul documento
  └───────────────┘

Usa il valore che compare stampato se stai copiando il numero dalla pagina; usa il fisico se stai contando le pagine del file.

Chiave OpenRouter (BYOK)

Per usare il motore llm inserisci la tua chiave. La chiave:

  • è usata solo per eseguire le traduzioni richieste;
  • non viene salvata sul server né scritta nei log;
  • resta nel tuo browser; i costi vanno sul tuo account OpenRouter.
  browser ──(chiave nella richiesta)──▶ server ──▶ pdf2zh_next
      ▲                                              │
      └────── la chiave NON viene conservata ─────────┘

Nel passo Motore, selezionando llm compare il campo: incolla la chiave (nascosta, con 👁 per mostrarla) e premi Verifica chiave e modello per un controllo immediato. Spunta «Ricorda in questo browser» per non reinserirla alla riapertura; Dimentica la cancella.

Se non hai una chiave, usa google o bing: funzionano subito e senza registrazione.

Download

  • Un unico PDF: le pagine tradotte in un solo file.
  • ZIP di pagine singole: un PDF per ogni pagina.

Apri il dettaglio del lavoro (clic sulla tessera) e usa il pulsante di download quando lo stato è done.

Installazione

Il modo più semplice è Docker:

docker run -d --name noesis -p 18080:18080 -v noesis-data:/data \
  ghcr.io/vigliafg/noesis-pdf-cloner-service:latest

In alternativa, dai sorgenti su Linux/macOS/WSL:

git clone https://github.com/vigliafg/noesis-pdf-cloner-service
cd noesis-pdf-cloner-service
./install.sh

Guida completa all'installazione (Windows, offline, API+worker): docs/INSTALL.md.

Configurazione

Il modo più semplice è la pagina Impostazioni, aperta dal computer che ospita il servizio:

http://127.0.0.1:18080/settings

Trovi limiti, prestazioni, pulizia, motore, la chiave OpenRouter e le opzioni legali. Modifica e premi Salva, poi riavvia: ./noesis restart (in Docker: docker compose up -d).

La pagina è privata: risponde solo dal computer locale (o da quello che ospita Docker). In alternativa, da console: ./noesis config --show, ./noesis config --set CHIAVE=VALORE, ./noesis config --list.

API e CLI

Ogni funzione del browser è disponibile via API REST (/api/v1) e da riga di comando:

./run-cli.sh libro.pdf -p 100-103 --src en --dst it --engine google

Per il motore llm da CLI: esporta OPENROUTER_API_KEY (consigliato) oppure usa --llm-api-key-file; --llm-api-key è comodo ma visibile in ps/history.

Dettagli in README.

Disinstallazione

./uninstall.sh            # scelta interattiva di cosa rimuovere
./noesis uninstall --all  # nessuna traccia

Con Docker: docker rm -f noesis (e rimuovi il volume noesis-data se non ti serve più).

FAQ

La traduzione è istantanea su alcune pagine: perché?

Sono pagine già in cache: lo stesso documento e la stessa lingua non vengono ritradotti.

Posso tradurre un libro intero?

Sì, con all. Consigliabile su testi che hai il diritto di elaborare.

La traduzione contiene errori?

È una traduzione automatica: verificala sempre. Vedi le note legali.

Dove finiscono i miei file?

Restano sul tuo server; documenti e artefatti vengono rimossi automaticamente (24h/72h). Vedi la Privacy.
